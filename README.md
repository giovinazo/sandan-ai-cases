# 산업단지 건설사업관리 AI 활용사례 소스 모음

산업단지 개발 실무에서 담당자가 생성형 AI(Claude)와 함께 직접 만들어 쓰고 있는 도구 다섯 가지의 소스입니다.
2026년 9월 개발실 워크숍 발표 「산업단지 건설사업관리 AI 활용사례」에서 소개한 내용이며, 다른 사업에서도 따라 쓸 수 있도록 공개합니다.

실제 사업 자료(측량 성과, 공문 원문, 도면, 좌표, 수집 자료 등)는 넣지 않았습니다.
각 폴더에는 **생성 프로그램과 가상 예시자료**가 들어 있어, 받은 그대로 돌려 보고 자기 사업 자료로 바꿔 쓸 수 있습니다.

## 다섯 사례

| 폴더 | 업무 단계 | 기능 한 줄 | AI가 한 일 한 줄 |
|---|---|---|---|
| [01_ortho-viewer](01_ortho-viewer/) | 측량 성과 활용 | 대용량 정사영상·표고를 담당자 PC에서 더블클릭으로 열고 거리·면적·높이를 잰다 | 영상 타일화·표고 계산·뷰어 제작 |
| [02_barrier-3d](02_barrier-3d/) | 환경영향평가 대응 | 방음벽 높이 대안별 배치·그림자·층별 창 시야를 3차원으로 비교한다 | 3차원 모델 제작, 생성형 이미지로 사람 눈높이 모습 제작 |
| [03_opinion-ledger](03_opinion-ledger/) | 인허가 협의 관리 | 판마다 형식이 바뀌는 협의의견 제출본(PDF)을 판독해 대장 엑셀과 대시보드로 만든다 | PDF 표 판독·대장화·총괄표 전수 대조 |
| [04_osint-monitor](04_osint-monitor/) | 사업 환경 모니터링 | 정보공개포털·뉴스·SNS의 공개정보를 매일 모아 한 화면에서 본다 | 수집·분류·요약 화면 자동 갱신 |
| [05_campus-guide-map](05_campus-guide-map/) | 홍보·분양 | 준공 전 현장에서 휴대폰으로 내가 선 블록과 바라보는 방향을 안내한다 | 도면을 공공지도에 맞추기(지리참조), 휴대폰용 지도 제작 |

## 공통 방식

- **누가**: 사업 담당자가 직접 (별도 용역·장비 비용 없음)
- **어떻게**: 생성형 AI에게 원자료와 목표를 주고, 생성 프로그램을 함께 만든다
- **산출물**: 더블클릭으로 열리는 HTML, 엑셀 대장, 정적 웹사이트
- **수정**: 자료가 바뀌면 자료만 바꿔 생성 프로그램을 다시 실행한다 (산출물을 직접 고치지 않는다)
- **검증**: 사람이 원문과 대조하는 단계를 반드시 둔다 (면적 검산, 총괄표 전수 대조, 생성 이미지 실측 등)

## 시작하기

1. 저장소를 내려받습니다: 초록색 **Code** 단추 → **Download ZIP**, 또는 `git clone`
2. 관심 있는 사례 폴더의 `README.md`를 엽니다. 준비물과 예시자료로 돌려 보는 순서가 적혀 있습니다.
3. 대부분 파이썬 3.10 이상이 필요합니다. 폴더마다 `requirements.txt`가 있으면 `pip install -r requirements.txt`로 준비합니다.

AI에게 맡기는 방법도 있습니다. Claude Code 같은 코딩 도구에서 이 저장소 폴더를 열고
"01_ortho-viewer 예시자료로 돌려 줘", "이 도구를 우리 사업 자료에 맞게 바꿔 줘"처럼 요청하면 README를 읽고 따라 합니다.

## 유의사항

- 개인정보(소유자 정보 등)와 협의 중인 사항은 도구에 넣지 않습니다.
- 공개정보 수집은 공개된 화면만, 요청 간격을 두고, 각 사이트 이용약관을 지켜 사용합니다.
- 생성형 AI의 결과는 초안입니다. **판단과 책임은 담당자에게 있습니다.** 수치는 반드시 원문과 대조하십시오.
- 예시자료의 기관·부서·수치·좌표는 모두 가상입니다.
