# 사례 5. 사업부지 안내 지도 (휴대폰 우선 웹)

준공 전, 아직 논밭인 사업부지에 서서 휴대폰을 켜면 **지금 서 있는 자리가 어느 블록이 되는지**, **어느 쪽을 바라보고 있는지**를 알려 주는 안내 지도.
사업구역 밖이면 경계까지 거리와 길찾기 링크를 보여 준다. 앱 설치 없이 웹 주소 하나로 쓰고, 홈 화면에 추가하면 앱처럼 열린다.

화면 구성: 지도 위 단추 3개(내 위치 · 전체 · 배경), 하단 시트 탭 4개(토지이용 · 블록 · 로드뷰 지점 · 안내)

이 폴더의 자료는 모두 **가상 예시**다. 위치·구역계·블록명·용도·면적은 지어낸 값이며 실제 사업과 관계없다.

## 1. 무엇을 하나

| 기능 | 내용 |
|---|---|
| 내 위치 추적 | `watchPosition` 으로 계속 따라가며 점과 정확도 원 표시 |
| 서 있는 블록 | 점이 들어 있는 블록을 판정해 카드에 크게 표시하고 지도에서 강조 |
| 바라보는 방향 | 기기 나침반으로 부채꼴 회전. 나침반이 없으면 걷는 중에 한해 이동 방향 사용 |
| 구역 밖 | 경계까지 거리(m)와 길찾기 링크 |
| 아주 먼 곳 | 지도를 옮기지 않고 거리와 길찾기만 안내(설정 `location.range_km`) |
| 블록·용도 카드 | 지도에서 누르면 면적·비율·설명 |
| 오프라인·홈 화면 | 서비스워커와 매니페스트(https 배포 시) |
| 판 표시 | 화면에 빌드 시각을 찍고, 새 판이 올라오면 ｢새로 받기｣ 안내 |

## 2. AI가 한 일과 사람이 검증한 일

| 구분 | AI(코딩 도우미) | 사람 |
|---|---|---|
| 도면 좌표화 | 지번 글자 위치를 기준점으로 쓰는 기법 제안, RANSAC 아핀 적합 코드 작성 | 기준점 오차·축척이 도면 표기(1:5,000)와 맞는지 확인 |
| 도형 추출 | 범례 색으로 용도 분류, 도로 차집합 산출 | **면적 검산**: 용도별 추출 면적을 계획 면적과 대조 |
| 위치 확인 | 편입 필지가 구역계 안에 드는 비율 계산 코드 | **원도면 대조**: 남북 방향 지물·하천·도로 선형을 위성사진과 겹쳐 눈으로 확인 |
| 화면 | 휴대폰 레이아웃, 위치·나침반·서비스워커 구현 | 현장에서 실제로 걸으며 블록 판정과 방향 확인, 문구 다듬기 |

실제 적용 경험: 기준점 수백 개로 중앙 오차 약 1.4m, 용도별 면적 편차 0.3% 이내. 그런데도 한 번은 **도형이 상하로 뒤집힌 채** 면적 검산을 통과했다(아래 함정 1). 사람의 원도면 대조가 빠지면 안 되는 이유.

- Python 3.10 이상
- `pip install -r requirements.txt` (지도 빌드만 할 때는 필요 없음. 배포 아이콘은 Pillow, 지리참조 시연은 pdfplumber·PyMuPDF·numpy·shapely)

## 6. 자기 사업으로 바꾸는 법

### 6-1. 구역계·블록 GeoJSON 준비

| 파일 | 필수 속성(이름은 설정 `data.fields` 로 바꿀 수 있음) |
|---|---|
| 토지이용 | `용도`, `면적_㎡`, `색상`. 이 중 `용도=구역계` 인 도형 하나가 사업구역 경계 |
| 블록 | `블록`, `용도`, `면적_㎡`, `색상`, (선택) `획지수` |
| 계획표(선택) | `용지[].구분`·`면적_㎡`·`설명` 카드 문구 |
| 로드뷰 지점(선택) | `지점[].번호`·`명`·`lat`·`lng`·`설명` |

좌표계는 WGS84 경위도(EPSG:4326). CAD·SHP 원본이 있으면 QGIS 등으로 바로 내보내면 되고, **좌표 없는 PDF 도면뿐이면** 아래 지리참조를 쓴다.

### 6-2. 도면 지리참조 원리와 절차

인허가 도서의 도면 PDF에는 좌표가 없는 경우가 많다. 하지만 CAD에서 뽑은 벡터 PDF라면 지적도의 **지번 글자가 위치를 가진 텍스트**로 남아 있다. 편입 필지 목록의 지번별 좌표(주소 지오코딩 등)와 짝지으면 도면 좌표를 실세계 좌표로 바꾸는 아핀 변환을 되살릴 수 있다.

1. 지적도 PDF 글자를 문자 행렬(방향)이 같고 바짝 붙은 것끼리 이어 붙여 지번 문자열 복원(CAD 글자는 한 자씩 따로 놓여 일반 추출로는 깨짐)
2. 도면에 한 번, 좌표 목록에도 한 번만 나오는 지번만 기준점으로 채택(같은 번지가 여러 리에 있으면 제외)
3. RANSAC 아핀 적합: 무작위 3점으로 변환을 세우고 가장 많은 점이 들어맞는 해를 골라 재적합. 지오코딩이 틀린 점은 자동으로 빠짐
4. 검증: 복원 축척이 도면 표기 축척과 같은가, 기준점 오차 중앙값이 수 m 이내인가
5. 같은 도곽으로 출력한 토지이용계획도에 같은 변환을 적용. 채움 색을 범례 색과 대조해 용도별로 묶고, 흰 바탕 합집합을 구역계로, (구역계 - 나머지 용도)를 도로로
6. **면적 검산과 위치 검산을 따로**: 면적은 계획표와 대조, 위치는 편입 필지 좌표가 구역계 안에 드는 비율(90% 이상)

시연:

```bash
python3 tools/georef_demo.py make        # 좌표 없는 합성 도면 2장 + 잡음·이상치 섞인 가상 지번 좌표
python3 tools/georef_demo.py run         # 변환 복원 → output/georef_landuse.geojson
python3 tools/georef_demo.py run --flip  # 함정 1 재현
```

```
기준점 186/202 채택 · 오차 중앙값 1.1m · RMS 1.34m · 최대 3.04m
복원 축척 1:5,001 · 회전 0.333°  (숨겨 둔 정답 1:5,000 · 0.35°)
면적 검산: 최대 편차 0.06%  → 통과
위치 검산: 편입 필지 좌표 204건 중 구역계 안 202건 (99.0%)  → 통과
[--flip] 면적 검산 통과 · 위치 검산 59.3% → 실패
```

실제 도면에 쓸 때는 `georef_demo.py` 의 `LEGEND_BAND_TOP`(범례 영역 제외선), 범례 색상, 지번 정규식(`JIBUN`, 예: ｢산12-3｣)을 도면에 맞게 고친다.

### 6-3. 설정 항목 (`config.example.json` → `config.json`)

| 항목 | 내용 |
|---|---|
| `site.title` · `heading` · `short_name` · `place_name` · `theme_color` · `contact` | 사업명·화면 제목·홈 화면 이름·길찾기 목적지 이름·색·연락처 |
| `notice.short` · `more` · `legal` | 상단 고지(승인 전 계획), 펼침 문구, 탭 아래 법적 효력 없음 문구 |
| `data.*` | 자료 파일 경로, 속성 이름 대응, 구역계 값, 용도 표시 순서, 면적 허용 편차 |
| `tabs` | 탭 차례와 이름(`plan` · `blk` · `rv` · `info`) |
| `info_html` | 안내 탭 본문 |
| `basemap.choice` | `osm`(기본) · `vworld` · `custom` · `local` · `none` |
| `links.*` | 로드뷰·길찾기 링크 형식(`{lat}` `{lng}` `{name}`). 비우면 단추 숨김 |
| `location.range_km` · `follow_zoom` | 이 거리보다 멀면 지도 이동 안 함, 따라갈 때 확대 수준 |
| `deploy.out_dir` · `cache_prefix` | 배포 폴더, 서비스워커 캐시 이름 |

브이월드 배경을 쓰려면 키를 **환경변수 `VWORLD_KEY`** 로 넘긴다(`config.json` 의 빈 칸에 적어도 되지만 그 파일은 저장소에 올리지 않는다). 키는 배포된 HTML 안에 그대로 보이므로 브이월드 쪽에서 사용 도메인을 제한해 둔다.

## 7. 배포 (https 정적 호스팅)

```bash
python3 tools/build_deploy.py            # dist/web/ 생성
python3 -m http.server -d dist/web 8000  # 내 컴퓨터에서 확인(localhost 는 https 와 같은 대우)
```

`dist/web/` 를 넷리파이·버셀·깃허브 페이지 등 정적 호스팅에 폴더째 올린다.

**https가 필요한 이유**
- 휴대폰 브라우저는 위치 API(geolocation)를 https(또는 localhost)에서만 허용한다. http 주소로는 ｢내 위치｣가 잡히지 않는다.
- 아이폰 나침반 권한 요청(`DeviceOrientationEvent.requestPermission`)도 보안 컨텍스트가 필요하다.
- 서비스워커는 https에서만 등록된다. file:// 에서는 등록 자체가 실패한다. 서비스워커가 있어야 오프라인에서도 화면이 뜨고 홈 화면에 추가된다.

로컬 타일을 동봉하려면 `basemap.choice` 를 `local` 로 두고 `python3 tools/build_deploy.py --tiles 타일폴더`(z/x/y 구조). 서비스워커가 같은 주소의 `tiles/` 를 캐시 우선으로 담아 통신이 끊긴 현장에서도 배경이 뜬다. OpenStreetMap 공개 타일은 대량 내려받기가 이용 정책상 금지이므로 캐시 대상에서 뺐다.

## 8. 함정 (실제로 겪은 것)

1. **pdfplumber y축 이중 반전.** pdfplumber 의 도형 좌표(`pts`)는 이미 위에서 아래로 재는 top 기준이다. PDF 원래 좌표계라고 생각해 `page.height - y` 로 한 번 더 뒤집으면 폴리곤이 상하로 뒤집힌다. 그런데 **면적은 반전에도 보존되어 면적 검산을 통과**한다. 위치 검산(편입 필지 포함률, 정상 99% 대 반전 59%)을 따로 두어야 잡힌다. 위치 검산 코드에서도 미터 좌표 도형에 경위도 점을 넣으면 엉뚱한 비율이 나오니 좌표계를 맞출 것.
2. **file:// 에서 fetch 차단.** 더블클릭으로 연 HTML은 옆 JSON을 읽지 못한다. 그래서 자료와 Leaflet을 HTML 안에 넣는다(인라인). `</script>` 가 자료에 섞여 태그가 끊기지 않게 `</` 를 풀어 쓴다.
3. **file:// 탭은 옛 판을 붙들고 있다.** 파일을 다시 빌드해도 이미 열린 탭은 새로 고치기 전까지 옛 내용을 보여 준다. 배포본에서는 서비스워커가 옛 화면을 붙든다. 화면에 **빌드 시각(판)** 을 찍고, 서비스워커 파일에도 판을 넣어 판이 바뀌면 반드시 새로 설치되게 했다. 새 판이 있으면 ｢새로 받기｣ 링크가 뜬다.
4. **휠 확대축소 직접 구현.** Leaflet 기본 휠 확대는 입력을 모았다가 한 번에 옮겨 트랙패드에서 툭툭 끊긴다. 기본 처리를 끄고 입력마다 목표 배율을 갱신해 화면 갱신마다 남은 거리의 30%씩 좁혀 간다(커서 기준 확대). 감도는 `step = -px / 200` 한 곳.
5. **위치 카드가 닫아도 되살아남.** 위치는 몇 초마다 들어온다. 그때마다 카드를 열면 닫아도 곧 다시 뜬다. 첫 위치에서만 열고 이후엔 열려 있을 때만 갱신한다.
6. **하단 시트가 안 접힘.** 세로 유연 항목의 `min-height:auto` 때문에 내용보다 작아지지 않는다. `min-height:0` 추가.
7. **배포 폴더를 통째로 지우면 호스팅 연결이 끊김.** `.vercel/`·`.netlify/` 를 지우면 다음 배포에 새 프로젝트가 생긴다. `build_deploy.py` 는 이 폴더를 남긴다. 계정·사이트 식별값이 들어 있으므로 저장소에는 올리지 않는다.
8. **404에 긴 캐시가 붙는 호스팅.** 타일을 나중에 채워도 예전 방문자는 오래 못 볼 수 있다. `_headers`·`vercel.json` 으로 화면은 매번 확인, 타일은 하루 캐시로 둔다.

## 9. 유의사항

- **승인 전 계획 고지.** 화면 상단과 탭마다 ｢승인 전 계획, 참고용, 법적 효력 없음｣을 상시 표기한다. 측량·경계 확정·재산권 판단에 쓸 수 없다는 점을 분명히 한다.
- **소유자 정보 배제.** 필지 소유자·주소·보상 관련 값은 넣지 않는다. `build_site.py` 는 자료에 `소유자`·`보상등급`·`실거래가` 등 항목이 섞여 있으면 빌드 때 떼어 낸다. 화면에 안 보여도 페이지 소스에는 실리기 때문이다. 설정 파일의 `_` 로 시작하는 설명 항목도 같은 이유로 뺀다.
- **공개 범위.** 1차는 내부·관계기관, 승인고시 뒤 대외 공개처럼 단계를 나누고, 협의 중인 사항(설치 주체·비용 부담 등)은 자료 파일 단계에서 뺀다.
- **배경지도 저작권.** OpenStreetMap 타일은 화면 오른쪽 아래 저작권 표기를 유지해야 한다. 이용자가 많아지면 자체 타일이나 상용 타일로 바꾼다.
